# Roadmap

## Now

- Publish the repo publicly.
- Pressure-test the v0.1 proof receipt schema.
- Pressure-test the first bounty template.
- Pressure-test reviewer rules.
- Pressure-test human and agent submission format.
- Invite early contributors and reviewers.

## v0.1

- Proof receipt schema:
  - id
  - track
  - artifact URL
  - acceptance check
  - submitter type
  - reviewer
  - verification state
  - reward state
- Bounty template:
  - problem statement
  - accepted artifact
  - verification method
  - reviewer requirement
  - reward terms
  - failure credit rules
- Reviewer rubric:
  - what reviewers attest to
  - what they do not attest to
  - conflict handling
  - later reproduction accountability
- Submission format:
  - submitter type
  - artifact
  - verification method
  - environment details
  - known limits
  - gaming risk

Drafts live in [docs/](docs/).

## v0.2

- Public receipt pages.
- Submission flow for humans and agents.
- Basic contributor profiles.
- Open bounty board backed by structured data.
- First real verified bounties.

## Later

- Funding pools.
- Reputation portability.
- Multichain settlement only if the work graph proves useful.
- Legal review before any token design.
