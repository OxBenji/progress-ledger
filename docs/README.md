## Current Principle

Progress Ledger should reward verified artifacts, not claims, status, affiliation, or hype.

The first version should answer four questions:

1. What was submitted?
2. What check proves it counts?
3. Who reviewed it?
4. What reward or reputation state changed because of that review?
